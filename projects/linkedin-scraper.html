LinkedIn comment scraper

A small personal tool: given a LinkedIn post, collect every comment with the commenter’s name and profile link into a CSV for analysis.

Type
Personal tool
Date
January 2025
Stack
Python, Selenium (Edge WebDriver), BeautifulSoup, pandas

Code on GitHub

Why a browser

LinkedIn comments sit behind a login and load a page at a time as you click “Load more comments”, so a plain HTTP request sees almost nothing. The tool drives a real browser instead.

How it works

  1. Log in with Selenium and Microsoft Edge WebDriver, then open the post.
  2. Switch the comment order to Most recent, so the full thread is reachable, not just LinkedIn’s top picks.
  3. Click “Load more comments” until the button stops appearing.
  4. Save the rendered page, then parse it separately with BeautifulSoup into three columns (name, profile URL, comment text) and write linkedin_comments.csv.
while True:
    try:
        load_more = WebDriverWait(driver, 5).until(
            EC.element_to_be_clickable((By.CSS_SELECTOR,
                "button.comments-comments-list__load-more-comments-button--cr"))
        )
        load_more.click()
        time.sleep(2)
    except TimeoutException:
        break  # no more comments to load

Keeping the raw HTML separate from the parsing step meant I could adjust the selectors and re-parse without hitting LinkedIn again.

Known limits

  • The selectors depend on LinkedIn’s current markup, including some generated class names, so they will need updating when the interface changes.
  • Credentials should come from environment variables rather than the script.
  • Scraping LinkedIn is against its terms of service; the tool is for personal, educational use on small volumes.
